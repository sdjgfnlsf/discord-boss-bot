# 메이플 보스 봇

디스코드 슬래시 명령어로 캐릭터의 일일/주간/보스 숙제 현황과 이번 주 보스 예상 수익을 확인하는 봇입니다.
길드원 각자 자기 넥슨 API 키를 등록해서 각자 자기 캐릭터 정보를 조회하는 구조예요.

## 1. 디스코드 봇 만들기 (최초 1회)

1. https://discord.com/developers/applications 접속 → **New Application** → 이름 입력(예: 메이플보스봇)
2. 왼쪽 메뉴 **Bot** 클릭 → **Reset Token** (또는 바로 보이는 토큰) → **복사**해서 안전한 곳에 저장 (이게 `DISCORD_TOKEN`)
   - "PUBLIC BOT"은 꺼두는 걸 추천 (본인 서버에서만 쓸 거면)
3. 왼쪽 메뉴 **General Information**에서 **Application ID** 복사 (이게 `CLIENT_ID`)
4. 왼쪽 메뉴 **OAuth2 → URL Generator**
   - SCOPES: `bot`, `applications.commands` 체크
   - BOT PERMISSIONS: `Send Messages`, `Use Slash Commands`, `Embed Links` 체크
   - 맨 아래 생성된 URL을 브라우저에 붙여넣고 접속 → 봇을 초대할 서버 선택 → 승인

## 2. 로컬 설정

1. 이 폴더에서 `npm install`
2. `.env.example` 파일을 복사해서 `.env`로 이름 바꾸고, 위에서 복사한 `DISCORD_TOKEN`, `CLIENT_ID` 붙여넣기
   - 테스트용으로 특정 서버에만 빠르게 명령어 넣고 싶으면 그 서버 ID도 `GUILD_ID`에 넣으세요 (서버 아이콘 우클릭 → ID 복사, 안 보이면 디스코드 설정에서 "개발자 모드" 켜기)
3. `npm run deploy` — 슬래시 명령어를 디스코드에 등록 (코드나 명령어 구조를 바꿀 때마다 다시 실행)
4. `npm start` — 봇 실행. 터미널에 "✅ 로그인 완료" 뜨면 정상

봇이 계속 떠 있어야 명령어가 동작해요 (터미널 창 닫으면 봇도 꺼져요). 컴퓨터를 계속 켜두시거나, Railway 같은 무료 호스팅으로 옮기시면 됩니다.

## 3. 컴퓨터 켤 때 자동 실행 (선택)

매번 터미널을 열어서 `npm start`를 치기 귀찮다면 `launch.vbs`로 자동화할 수 있어요.

1. `launch.vbs` 파일에서 마우스 오른쪽 클릭 → **바로 가기 만들기**
2. `Win + R` → `shell:startup` 입력 → 열린 폴더에 방금 만든 **바로 가기**를 넣기 (원본 파일이 아니라 바로 가기여야 해요)
3. 다음에 컴퓨터를 켜면 검은 터미널 창 없이 봇이 백그라운드로 자동 실행됩니다.

(`launch.vbs`는 자기 자신이 있는 폴더를 기준으로 `npm start`를 실행하므로, 프로젝트 폴더를 통째로 옮기지만 않으면 경로를 따로 수정할 필요는 없어요.)

## 4. 사용법

디스코드 채널에서 `/도움말`을 치면 아래 내용이 봇 안에서 바로 보여요.


- `/등록 api키:<키> 캐릭터명:<이름>` — 캐릭터 등록 (나만 보이는 응답)
- `/캐릭터목록` — 등록한 캐릭터 확인
- `/숙제 [캐릭터명]` — 오늘/이번 주 숙제 현황 + 보스 예상 수익 (캐릭터명 비우면 등록된 전체)
- `/삭제 캐릭터명:<이름>` — 캐릭터 등록 해제
- `/가격수정 보스명:<이름> 난이도:<선택> 가격:<메소>` — 내 기준 결정석 가격 수정 (기본값은 미리 넣어뒀어요)
- `/큐브통계 [캐릭터명] [시작일] [종료일]` — 기간 내 큐브 사용 통계 (기본: 최근 7일)
- `/스타포스통계 [캐릭터명] [시작일] [종료일]` — 기간 내 스타포스 강화 통계 (기본: 최근 7일)
  - 날짜는 `YYYY-MM-DD` 형식 (예: `2026-09-01`)
  - 넥슨 API가 하루 단위로만 조회되는 구조라, 내부적으로 날짜를 하루씩 돌면서 모아요. 기간이 길면 시간이 좀 걸리고, 최대 31일까지만 한 번에 조회돼요.
  - **아직 정확한 응답 필드명을 검증 전**이라 종류별/결과별 집계가 부정확하거나 비어있을 수 있어요. 결과 임베드에 "원본 데이터 샘플"이 같이 나오니, 그거 캡처해서 보여주시면 집계 로직을 정확하게 다듬을게요.
- `/리마인더 일일설정 시간:HH:mm` — 매일 그 시간(KST)에 일일 숙제 미완료면 DM
- `/리마인더 일일끄기` — 일일 알림 끄기
- `/리마인더 일일캐릭터 캐릭터명:<이름> 포함:<true/false>` — 특정 캐릭터를 일일 알림 대상에서 빼거나 다시 넣기 (기본은 전체 포함)
- `/리마인더 일일목표설정 항목명:<이름> 목표횟수:<숫자>` — 몬스터파크처럼 실제로 다 못 채우는 항목의 완료 기준을 직접 정하기
- `/리마인더 일일목표해제 항목명:<이름>` — 설정한 목표치 지우고 게임 기본 최대 횟수로 되돌리기
- `/리마인더 주간설정 요일:<선택> 시간:HH:mm` — 그 요일마다(주 1회) 주간+보스 미완료면 DM
- `/리마인더 주간끄기` — 주간+보스 알림 끄기
- `/리마인더 주간캐릭터 캐릭터명:<이름> 포함:<true/false>` — 특정 캐릭터를 주간+보스 알림 대상에서 빼거나 다시 넣기 (기본은 전체 포함)
- `/리마인더 상태` — 일일/주간 알림 설정 + 캐릭터별 포함 여부 확인

## 알아두면 좋은 점

- **각자 자기 API 키로 등록**해야 그 계정 캐릭터의 스케줄러(숙제 체크) 데이터를 가져올 수 있어요. 남의 키로는 남의 캐릭터가 조회 안 돼요.
- 데이터는 이 폴더의 `data/users.json`에 저장돼요. **API 키가 평문으로 저장**되니, 이 폴더 자체를 다른 사람과 공유하지 마세요.
- `/숙제` 명령어는 공개 채널에 보이는 응답이에요 (친구들끼리 서로 확인하기 좋으라고). 등록/삭제/가격수정/리마인더는 본인만 보이게 처리했어요.
- **리마인더는 일일 / 주간+보스가 완전히 독립적이에요.** 같은 시간으로 설정해도 각자 따로 DM이 가고, 알림도 따로 켜고 끌 수 있어요. 일일은 매일, 주간+보스는 지정한 요일에 주 1회만 가요.
- 봇이랑 같은 서버에 있어야 하고, 디스코드 설정에서 "서버 멤버의 다이렉트 메시지 허용"이 켜져 있어야 DM을 받을 수 있어요. 그날 미완료 항목이 없으면 DM 자체를 안 보내요 (스팸 방지).
- 게임 안에서 스케줄러에 등록해둔 항목만 표시돼요 (넥슨 API 특성).
- 봇을 여러 서버에 초대해도 유저 데이터는 디스코드 계정 기준으로 공유돼요 (서버별로 따로 등록하는 게 아님).
